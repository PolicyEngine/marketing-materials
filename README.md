# PolicyEngine Marketing Materials

Marketing materials for conferences, events, and outreach.

## Contents

- `trifold/` - Trifold brochures for conferences (APPAM, etc.)

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view materials.
